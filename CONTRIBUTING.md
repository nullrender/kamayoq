# Contributing

Kamayoq is in early development and does not take code contributions yet: the design is still moving, and pull requests would likely go stale. Bug reports and questions are welcome as issues.

When it opens to contributions, the rules for code are in [AGENTS.md](AGENTS.md): Kotlin and Jetpack Compose, rules in `core` tested on the JVM, a failing test before each fix, one change per commit, and interface texts in English with Brazilian Portuguese alongside.
